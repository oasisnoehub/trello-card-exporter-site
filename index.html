Trello 卡片导出

把你的 Trello 数据真正拿到手里。

在 Chrome 商店安装 隐私政策
Trello 官方的整站导出只对 Premium 工作区管理员开放。免费版用户只能一块板一块板手动导， 而且导出的 JSON 里附件只是一个链接——Trello 一删，附件就没了。 这个扩展补上这个缺口。

导出什么

  • 卡片正文，原样保留 Markdown 格式
  • 清单及每一条的勾选状态
  • 标签、成员、截止日、归档状态、自定义字段
  • 评论正文（可选）
  • 附件原文件，图片 / PDF 等按看板分目录

三种产物

HTML双击就能看，图片全部指向本地，断网也能读
Markdown丢进 Obsidian / Typora 继续编辑
CSV / JSONExcel 筛选，或用程序二次处理

两个细节

  • 不用申请 API Key。点一次「连接 Trello」授权即可，全程只读权限。
  • 正文里的图片会本地化。Trello 卡片正文贴的图默认是需登录的外链，导出来是一堆打不开的链接；这里会把它们换成下载到本地的文件。

隐私

扩展没有服务器。Token 只存在你自己浏览器里，数据只在你机器上流转，不上传、不分析、不分享。 详见 隐私政策。

安装（开发者模式）

1. 打开 chrome://extensions
2. 右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」，选择扩展目录
4. 点工具栏图标，在侧边栏面板里操作
